# Creation interface pass

Events: optional cover photo; name; start/end; physical or online meeting place; searchable Space/Society context; capacity; ticket price; attendance mode; organizer contact; description. Existing event notes reopen with all fields and photos. Events remain private local drafts, not public listings or issued tickets.

Pings: optional cover photo; name; plan; start/end; capacity including organizer; meeting place; searchable Space/Society/Event context; invite selections. No unrelated default photo. Start/end, capacity and location validation are shared with event creation.

Spaces: optional photo, editable category, identity, description, address and representation consent. Societies: optional photo, name, purpose, visibility and membership mode. Offerings: optional photo, name, type, price, editable price basis, options and conditions. Local offering photos and options are used by browsing and request forms.

Channels: optional photo, name, headline, introduction, expected posting rhythm and searchable context links. No automatically inserted collections. Channel updates support optional photos, title, text, type, collection, pin and context. Photos render on channel identities and updates.

Other creation interfaces checked: Rizz posts and chapter media already accept photos/video; chapter notes/tasks/event links keep their appropriate specialised fields; Society topics/chats have title, opening note and conversation type; trips retain joined-plan context, route, departure, capacity and instructions, with no preset seat count; service request forms retain their product/service-specific fields. No media field added where the object does not need media.

Photo controls support preview/change/remove, JPEG/PNG/WebP, 10 MB input limit, resizing to 1200 px and a bounded compressed result. Storage is device-local; existing workspace storage errors remain surfaced. No cloud upload or publishing integration is fabricated.

Automated checks cover gathering validation and media round trips. Browser confirmed both Event and Ping field sets. Browser file chooser test did not produce a preview, so upload interaction was not independently confirmed end-to-end in this pass.
