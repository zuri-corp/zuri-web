## Open and run

Install Node.js 22.15 or newer (Node 24 recommended), open this folder in a terminal, and run:

```
npm ci
npm run build
npm start
```

Open http://localhost:3000. No secret keys are included. `.env.example` lists deployment settings. The populated preview works without connecting a database.
